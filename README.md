The Electricity Bill Calculator is a Java-based application designed to calculate the electricity bill based on the units of electricity consumed by a user. It helps users estimate their electricity charges quickly and accurately using predefined tariff rates.

The application provides a simple and user-friendly interface for entering electricity consumption details and generating the total bill amount.

🎯 Objectives

To calculate electricity bills based on units consumed.

To apply predefined electricity tariff rates.

To reduce manual calculation errors.

To provide a simple and efficient billing system.

🛠️ Technologies Used

Programming Language: Java

Concepts Used: Classes, Objects, Methods, Conditional Statements, Loops

IDE: VS Code / Eclipse / IntelliJ IDEA

✨ Features

User Input: Accepts consumer details and electricity units consumed.

Bill Calculation: Calculates the bill based on electricity usage.

Tariff System: Applies different rates according to consumption slabs.

Consumer Details: Displays customer information.

Bill Generation: Generates the total electricity bill.

Additional Charges: Includes applicable additional charges if configured.

Bill Display: Displays the calculated bill in a readable format.

Input Validation: Checks user inputs to avoid invalid entries.

⚙️ How to Run the Project

Step 1: Clone the Repository

git clone https://github.com/your-username/electricity-bill-calculator.git

Step 2: Open the Project

Open the downloaded project folder in VS Code, Eclipse, or any Java IDE.

Step 3: Compile the Java Program

javac ElectricityBillCalculator.java

Step 4: Run the Program

java ElectricityBillCalculator
